# Textos de FemCoders Club

Al crear o editar textos visibles, sigue [la guía de tono](docs/tono-editorial.md).
Se aplica también a botones, mensajes de error, ayudas de formularios y metadatos.
Revisa el texto final en contexto: una regla escrita no sustituye la revisión.
Conserva los cambios existentes del usuario y limita las modificaciones al encargo.
